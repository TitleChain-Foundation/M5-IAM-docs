dagny.m5bank.app can be installed as the **M5** app:

| Browser | How |
| --- | --- |
| Chrome or Edge | Choose **Install** in the address bar |
| Safari on Mac | **File → Add to Dock** |
| Safari on iPhone or iPad | **Share → Add to Home Screen** |

The app opens on the home page, with shortcuts to **Start free** and **Dagny's closet**.
