| Word | Meaning |
| --- | --- |
| **Activated** | Set up and working for its holder in the pre-launch environment |
| **Live** | Open to the public |
| **Pending launch** | Built and being tested; opens at launch; the private waitlist is open |
| **Simulated** | Run end to end with sample records; no value moves and no official record is created |

The free IAM is the first thing to go live.
