TitleChain Foundation supports the industry's open standards and protocols and has embedded them in the M5Protocol, for everyone to use. Together they serve the aim of the proposed Sovereign Compute Access Act: open access for all, with a human at the root of every agentic and future AI service.

| Standard | From | Used for | Relationship |
| --- | --- | --- | --- |
| x402 | x402 Foundation (Linux Foundation) | Payment conditions on requests and notices | Featured: embedded as a working reference |
| x401 | x401 specification (draft) | Proof of identity or attribute before access or delivery | Featured: embedded as a working reference |
| Proof-of-Control | LF Decentralized Trust | Showing which human or entity an agent acts for | Working group participant and contributor |
| Model Context Protocol, AGENTS.md | Agentic AI Foundation (Linux Foundation) | How agents connect to tools and read instructions | Featured: embedded as a working reference |
| DIDs, Verifiable Credentials | W3C | Reusable identity and credentials | Embedded in the M5Protocol |
| Solid pods | Open Data Institute | The container layout of the M5POD | Embedded in the M5Protocol |
| SP 800-53 Rev. 5, CSF 2.0 | NIST | Security controls in the threat model | Embedded in the M5Protocol |
| SPDX | Linux Foundation | Licence identifiers on software titles | Embedded in the M5Protocol |
| Matrix | Matrix.org Foundation | Member messaging and notices | Embedded in the M5Protocol |

TitleChain Foundation has applied for membership of the Linux Foundation and LF Decentralized Trust; both applications are pending.

:::note
This is the Foundation's own implementation and testing. It is not a certification, an audit, or an endorsement by any of these bodies.
:::
